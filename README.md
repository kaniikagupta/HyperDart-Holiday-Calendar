🌍 HyperDart Holiday Calendar

A standalone HyperDart component for discovering and displaying public holidays around the world.

The component is designed to make holiday-related searches simple and accessible through a clean, interactive interface. It is built using React, Vite, Material UI and HyperDart.

🚀 Features
🌎 Search for public holidays worldwide
📅 Holiday calendar interface
🔍 Supports natural holiday-related queries
🌍 Designed for different countries and regions
⚡ Fast and interactive React-based UI
🧩 Built as a standalone HyperDart component
📱 Responsive user interface
🔗 Designed to integrate with the HyperDart search platform
💡 Example Queries

The component supports holiday-related queries such as:

Public holidays
Public holidays in India
Holidays in USA
Bank holidays
Holiday calendar
Public holidays this year

⚙️ Installation

Clone the repository:

git clone https://github.com/kanikagupta/HyperDart-Holiday-Calendar.git

Move into the project directory:

cd HyperDart-Holiday-Calendar

Install dependencies:

npm install
▶️ Run Locally

Start the development server:

npm start

The project uses Vite for local development.

🏗️ Build

To create a production build:

npm run build

🎯 HyperDart Integration

This project is packaged as a standalone HyperDart component.

The component configuration defines holiday-related keywords including:

holiday
holidays
public holiday
public holidays
bank holiday
bank holidays
holiday calendar

These keywords allow the component to be associated with relevant holiday searches.

📦 Component Configuration

The project includes:

hyperdart.config.js — HyperDart component configuration
resource.json — resource schema/configuration
searchData.json — search/component data
vite.config.js — Vite build configuration
